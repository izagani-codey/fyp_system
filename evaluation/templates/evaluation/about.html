About the FYP Evaluation Process

How the UniKL MIIT FYP conference-style evaluation works

Evaluation Overview

The FYP Evaluation Management System provides a structured, transparent process for evaluating Final Year Projects at UniKL MIIT. Projects are evaluated in a conference-style format by expert judges assigned by the Programme-In-Charge (PIC).

1

Student Registration

Students register an account and create or join a project group. Each project requires a title, programme, section, and supervisor name.

2

Project Approval

The PIC reviews all submitted project registrations and approves or rejects them before the registration deadline.

3

Submission

Approved project leaders submit their abstract (text or PDF) and a video presentation link (YouTube / Google Drive).

4

Judge Assignment

The PIC assigns one or more approved judges to each accepted project. Judges receive a notification with project details.

5

Evaluation

Judges review the abstract, PDF, and video, then submit scores using the active evaluation template and criteria configured by PIC.

6

Results

The PIC compiles all scores and publishes winners and announcements on the public announcements page.

Dynamic Evaluation Criteria

PIC controls the active evaluation template, criteria names, descriptions, ordering, and maximum scores. Judges score each active criterion and the system calculates totals automatically.

Important Notes

  • Evaluation scores are private — visible to PIC only.
  • Students will not see individual evaluation marks.
  • Judges evaluate non-anonymously.
  • PIC publishes winners and announcements publicly.
  • All deadlines are enforced by the system.
